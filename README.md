# CLEC 双典 · 简介与大纲

基于目录下两本 PDF 自动提取目录与正文，为每本书生成**简介**与**大纲**，并用前端单页应用（SPA）呈现。整体采用墨金极简风格，呼应「金融圣经 / 宝典」的内容气质。

## 书籍

| 书名 | 版本 | 页数 | 结构 |
| --- | --- | --- | --- |
| 理财圣经（CLEC 版） | v3.4.1（2026/5 修订） | 97 | 金科玉律篇 · 8 条铁律 · 29 节 · 4 附录 |
| CLEC 宝典（SC 完整版） | V1.14.2（网络版，2026/8/14） | 559 | 六篇 · 27 章 · 8 实战附录 |

两书核心宣言一致：**富有是天赋，快乐是人权**。

## 功能特性

- **双书切换**：顶部标签在《理财圣经》与《CLEC 宝典》间切换。
- **简介**：每本书三段式导读，概括主旨、体系与价值。
- **大纲**：
  - 理财圣经 —— 以「理财铁律」为分隔的平铺章节列表（29 节 + 9 条铁律分隔 + 4 附录）。
  - CLEC 宝典 —— 六篇可展开/收起的手风琴（27 章）+ 附录与尾声。
- **视觉**：墨底金线、衬线标题、滚动渐显、响应式适配移动端。

## 技术栈

- **Vue 3**（全局构建 `vue.global.prod.js`，本地引入，免构建、免 CDN）
- 原生 CSS（CSS 变量 + Grid/Flex，无 UI 框架依赖）
- 纯静态站点，可直接用任意静态服务器托管

## 本地预览

```bash
cd site
python -m http.server 8123
# 浏览器打开 http://127.0.0.1:8123/index.html
```

> 直接双击 `site/index.html` 亦可（相对路径资源可正常加载）。

## 数据来源与说明

- 提纲与简介由 PDF 自动提取（PyMuPDF 解析目录/正文）后整理而成，条目数已与原书核对一致。
- 内容仅供阅读参考，不构成任何投资建议。

## 自定义 / 扩展

- **修改内容**：编辑 `site/assets/app.js` 中 `books` 数组（简介 `intro`、大纲 `outline`）。
- **调整风格**：修改 `site/assets/styles.css` 顶部的 CSS 变量（`--gold`、`--bg` 等）。
- **新增书籍**：在 `books` 数组中追加对象，并在 `index.html` 标签栏同步即可。
